# 太阳系层次变换实验报告
## 1. 项目说明
本项目基于WebGL + Angel库（initShaders.js、MV.js）实现太阳系层次动画。
采用矩阵嵌套变换实现天体运动效果：太阳可以自转，行星以指定角速度围绕太阳公转，月球围绕行星公转；太阳、行星、月球均自带自转；代码支持透视投影、正交投影两种模式实时切换，用于对比两种投影效果；同时支持动画暂停、全局速度调节、公转平面倾角调节、轨道显示开关，不同天体使用区分色便于观察嵌套变换关系。

## 3. 变换嵌套树（核心层次结构）
> 说明：Angel库中 `mult(A,B)` 等价矩阵乘法 `A × B`，变换执行顺序为先执行B，后执行A。
> 行星公转原理：先完成自转、缩放，再平移到指定轨道距离，最后施加公转旋转矩阵，实现绕原点（太阳）旋转。
> 月球为二级嵌套：跟随行星的全部变换，再叠加自身绕行星的公转与自转。

## 4. 矩阵构造说明
1. **视图矩阵 View**
`view = lookAt( vec3(0,12,18), vec3(0,0,0), vec3(0,1,0) )`
相机放置在 `(0,12,18)` 位置，看向场景原点（太阳位置），Y轴为向上方向。

2. **投影矩阵（界面按钮实时切换）**
- 透视投影：`perspective(45, aspect, 0.1, 20)`
45°视场角，aspect为画布宽高比，近裁剪面0.1，远裁剪面20；具备近大远小的透视效果，模拟人眼视觉。
- 正交投影：`ortho(-8, 8, -6, 6, 0.1, 20)`
固定观察边界，无透视形变，物体屏幕大小不会随距离改变。

3. **行星模型矩阵**
`M = 公转旋转矩阵 × 平移矩阵 × 缩放矩阵 × 自旋转矩阵`

4. **模型视图矩阵**
`modelView = view * M`

5. **顶点颜色**：太阳、行星、月球配置独立顶点颜色，直观区分不同天体，便于观察嵌套变换层级。

## 5. 双投影对比截图说明
- 透视投影截图（透视投影.png）
启用perspective投影，画面存在近大远小效果，距离相机更远的行星视觉上更小，空间立体感更强，贴近人眼真实观察效果。

- 正交投影截图（正交投影.png）
启用ortho正交投影，不存在透视收缩，所有行星的屏幕显示尺寸保持稳定，不会因为远近发生大小变化，适合观察物体相对位置。

对比总结：透视投影侧重真实视觉渲染；正交投影消除透视变形，适合工程绘图、保持物体比例不变。

## 6. 录屏说明
录制时长：10秒
内容：太阳持续自转，行星绕太阳公转，月球跟随行星公转；太阳、行星、月球各自带有自转。天体使用不同颜色区分，可开启轨道辅助观察层级嵌套变换，支持实时切换投影、调速、开关轨道。

## 7. 运行方式
1. 将整个`solar`文件夹放在本地；
2. 双击`index.html`，使用浏览器打开运行；
3. 切换投影：点击界面按钮【切换投影】，实时在透视、正交投影之间切换；
4. 其他交互：支持暂停动画、拖动滑块调节全局速度、调节公转倾角、勾选框控制轨道显示。

## 8. 实验小结
本实验利用矩阵乘法顺序实现层次嵌套变换，月球继承行星的全部变换，还原二级天体系统。通过两种投影模式对比，直观理解投影矩阵的作用；增加轨道、分色、调速等交互，方便观察矩阵变换的先后顺序与嵌套关系。
